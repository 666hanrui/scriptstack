# GeoWorld 数字地球综合地理互动教学平台

## 项目简介
GeoWorld 是一套以 3D 数字地球为核心的综合地理互动教学平台，融合自然地理、人文地理、世界景观、AI 讲解和任务挑战。

## 核心功能
- 3D 数字地球
- 世界景观探索
- 地球运动实验室
- 水循环与积雨云模拟
- AI 地理老师
- 任务挑战

## 技术栈
**前端**：React + TypeScript + Vite + React Three Fiber
**后端**：Spring Boot + H2
**数据**：JSON + H2 自动装载

## 启动方式

**前端**：
```bash
cd geoworld-frontend
npm install
npm run dev
```

**后端**：
```bash
cd geoworld-backend
mvn spring-boot:run
```

## 演示流程
首页 → 数字地球 → 景观探索 → AI 老师 → 地球运动 → 水循环 → 任务挑战
