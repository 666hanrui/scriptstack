# GeoWorld 项目说明文档 (Project Manual)

## 1. 项目简介
**GeoWorld** 是一款基于 Tauri 2 构建的跨平台桌面应用，旨在通过生动的地理数据可视化与 AI 互动技术，打破传统地理教育的枯燥性，为中学生群体提供一个“能看、能问、能练”的探索式学习平台。

## 2. 核心系统模块
### 2.1 探索与发现 (Explore)
- 囊括了 25 个全球代表性地理景观点（如东非大裂谷、青藏铁路等）。
- 首创“双轨数据呈现”，即在同一景观中同时展示 `natural_background`（自然成因）与 `human_geography`（人类活动），深度贯彻“人地关系”的地理学核心素养。

### 2.2 知识图谱库 (Knowledge Base)
- 收录了 40 个精细分类的地理核心知识点（涵盖地球运动、板块、气候、地貌、洋流等）。
- 通过 `related_landmarks` 字段与探索页数据双向绑定，实现从具体现象到抽象理论的无缝跳转。

### 2.3 AI 地理导师 (GeoTeacher)
- 集成了大语言模型（LLM）的智能体，设定为幽默、渊博的地理老师。
- **特色功能**：不仅提供通俗易懂的解答，还具备极强的防偏题（防越狱）机制，并在每次回答末尾主动向学生抛出启发性问题。

### 2.4 情境化任务挑战 (Task Challenges)
- 内置 8 大情境任务（如扮演气象局长、城市规划师）。
- 利用 JSON 预埋的 Keywords（关键词匹配算法），对学生的开放式回答进行智能校验，提供鼓励性与引导性的兜底反馈。

## 3. 适龄化与内容审核规范
- **通俗性**：避免过深的学术术语。如将“洋流”比喻为“隐形传送带”，将“死海密度”与“躺着看报纸”结合，极大地贴合了中学生的心智模型。
- **准确性**：所有经纬度坐标、海拔数据、洋流分类均经过严格校对。
- **价值观**：强调“可持续发展”，在内容中多次强调人类改造自然必须尊重自然规律（如纽芬兰渔场衰落的惨痛教训）。

## 4. 技术栈概述
- **前端框架**：WebView 渲染（HTML/CSS/JS）。
- **后端服务**：Rust (src-tauri)，提供极致的运行性能。
- **数据持久化**：SQLite (rusqlite)，确保本地数据的安全与快速响应。
- **网络与 AI**：reqwest (rustls-tls) 处理外部 LLM 流式请求。

## 5. 安装与运行说明
请参考项目根目录的 `README.md` 执行 `npm run tauri dev` 进入开发模式体验。
