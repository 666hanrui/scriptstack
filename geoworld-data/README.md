# GeoWorld 内容数据包 (v0.1)

本项目是 GeoWorld v0.1 版本的内容与数据交付物，旨在为前端展示和后端开发提供完整、规范的初始数据支撑，并确立 AI 互动核心体验。这些成果由内容、AI与文档代理在第一周内完成。

## 📁 交付物清单与目录结构

- `knowledge.json`：包含 20 个精选核心地理知识点（覆盖地球运动、板块、气候、地貌及人文可持续发展等），具备结构化字段与关联挑战题。
- `landscape.json`：包含 15 个全球代表性地理景观点数据（如珠峰、马里亚纳海沟、东非大裂谷等），包含精确经纬度坐标、多媒体占位及与知识点的双向关联。
- `ai_teacher_prompt.md`：AI 地理老师（GeoTeacher）的人设说明、System Prompt 及 5 个典型场景的互动问答指南。
- `ai_teacher.json`：将 AI 老师的提示词与测试问答数据转换为 JSON 格式，供后端开发直接加载与 API 测试使用。
- `ui_copy_and_demo.md`：提供了首页和各个模块页的前端展示 UI 文案（含空状态提示），以及一份详尽的 5 分钟汇报演示脚本（Demo Script）。

## 🌟 核心设计亮点

1. **闭环的关联体验**：通过 `related_landmarks` 和 `related_knowledge_points` 字段，实现数据间的相互引用，让学生在“看景”与“学理”之间自然流转。
2. **生动的 AI 互动**：GeoTeacher 不仅能幽默作答，还内置了**防越狱策略**（将偏题内容巧妙拉回地理话题）和**启发式挑战**，极大提升了教学价值。
3. **数据即用性**：所有的产出均严格按照技术团队约定的标准字段进行格式化，保证了高质量 JSON 输出，降低了前后端集成的门槛。
